# 发布记录与安装说明

## v1.1（versionCode 2）

安装包：`词刷-背单词-v1.1.apk`（7.7 MB，已签名，versionName 1.1）

### 本版变更

- 词库全部替换为开放许可语料：ECDICT（MIT）释义 + CMUdict 转写 IPA 音标 + Tatoeba（CC BY 2.0）双语例句
- 审查并修正了发音异常的单词：优先使用 CMUdict 美音转写，黙弃了带杂字符的旧音标
- 「不熟 / 熟 / 熟练」三个操作按钮从顶部操作栏移至卡片底部拇指热区，单击即翻到下一词
- 新增设置项：翻页时自动朗读单词（可关闭）
- 答题后有短暂停顿展示正确答案，再自动进入下一词

### 安装方式

1. 下载 `词刷-背单词-v1.1.apk`
2. 手机设置里允许「安装未知来源应用」
3. 点击 APK 安装，首次启动会加载词库（示例数据，约 1 秒）

> 完整词库（四级 5351 / 六级 7106 / 专升本 4649）不在仓库内，用 `tools/build_open_words.py` 重建后覆盖 `app/src/main/assets/` 即可，详见 `docs/rebuild-data.md`。

### 已知限制

- 未上架应用商店，无自动更新
- 发音依赖系统 TTS，部分机型无离线英文语音包时需联网
- 卸载会清空学习进度（未做云同步）

## 给维护者：发布 Release 的步骤

GitHub 连接器只能写文本内容，二进制安装包需在网页端上传：

1. 打开 `https://github.com/Wizard679/word-flash/releases/new`
2. Tag 填 `v1.1`，Target 选 `main`，标题填 `词刷 v1.1`
3. 说明区粘贴上面「本版变更」+「安装方式」
4. 把本地的 `词刷-背单词-v1.1.apk` 拖进附件区，等上传完成
5. 点 **Publish release**
